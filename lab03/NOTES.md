git diff - показывает разницу между двумя указанными коммитами.
git show - показывает разницу между указанным и прошлым коммитом
git log - Показывает историю коммитов в обратном хронологическом порядке
git log -S - Показывает коммиты в которых есть указанная строка
git blame - Показывает авторство каждой строки файла, для каждой строки отображает коммит и автора

git restore Восстанавливает файл из индексной области в рабочую директорию
git restore --source=... Позволяет восстановить файл из конкретного коммита, ветки или тега

Различия между тегом и веткой в том, что тег - неподвижный указатель конкретного коммита, а ветка - подвижный указатель, продвигающийся в перёд с каждым новым коммитом
