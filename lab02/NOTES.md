Рабочая папка - это текущие файлы на дисске
Индекс - это состояние файлов(обновляются git.add)
Коммит - это запись файла системы в его состоянии в какой-то момент времени
Git - программа контроля версий
Github - сервис с размещением репозитория, участников, использованием Git
git status - отображает статус репозитория в текущий момент
git diff - сравнение текущей и предыдущей версии
git diff --staged - подготовление к сравнению
Ветка - ссылка на коммит, это не копия файлов, а удобный инструмент для параллельной работы. 
При новом коммите в Git с веткой: ветка не «меняется» целиком — меняется только то, на какой коммит указывает её указатель. 
Слияние веток в Git — это процесс интеграции изменений из одной ветки в другую.
